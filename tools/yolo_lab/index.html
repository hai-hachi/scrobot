1 · Synthetic dataset generator

Build a fresh Lighting Lab calibrated court, spawn the production shuttle meshes, reposition a triggered camera, and save synchronized RGB + mesh-projected YOLO labels. The old collector's changed/stable render check is retained.

Dataset config comes from the Camera tab's camera_lab.yaml and Scene tab's yolo_lab.yaml. A new timestamped dataset is created for each capture; old datasets are not overwritten.

Runs the imported Ultralytics training script with saved epochs, batch and imgsz. Starts from the selected checkpoint, not random weights. Automatically stops Gazebo to free GPU capacity.
