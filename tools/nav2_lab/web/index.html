Global planner comparison

Send the same start/goal to each Nav2 planner. Planner-only runs do not move the robot. Compare path length, point count, computation time, and route geometry.

NavFn

Conventional costmap-based path planner. Configured with A* search in this lab; the production baseline.

Smac 2D

Cost-aware 2D A* with smoothing. Useful for evaluating more natural paths through the court.

Theta*

Any-angle line-of-sight planning. Good for comparing directness and corner behavior.

All planners receive the same global costmap and footprint. A map-to-odom transform is not required; this isolated test uses odom as the global frame.

Path-following controller comparison

Execute a planner-generated path through Nav2's real FollowPath action and observe tracking against the path.

Regulated Pure Pursuit

Geometric lookahead controller with curvature-aware speed regulation. The existing SCROBOT baseline.

DWB

Samples velocity commands and scores simulated trajectories using configurable critics for goal progress and obstacle avoidance.

MPPI

Sampling-based predictive optimization using a differential-drive model. More computationally intensive.

The production wheel-RPM limiter stays in the command pipeline. Its intervention can affect how closely each controller tracks its path, which is part of the real-system result.
