Shared parameters

Same reference speed, tolerances and progress checks for both controllers. These values are held constant for a fair comparison.

Wheel envelope: |v| + 0.21|ω| ≤ 0.50 m/s (physics-locked). ROS control 25 sim-Hz, wheel loop 100 sim-Hz. Gazebo speed is the common cap above the page.

Wheel and motor physics come from your saved Mobility Lab; odometry rates come from Odometry Lab. The floor uses the validated contact model.

RPP tuning

Nav2 Regulated Pure Pursuit. Tune lookahead, curvature-based slowdown and rotate-to-heading behavior.

Velocity-scaled lookahead uses min/max distance and lookahead time; fixed distance takes effect when disabled. Minimum speeds are capped by the shared desired speed in the generated Nav2 YAML.

SMC tuning

Custom sliding-mode tracker. Tune convergence, the continuous switching boundary, curvature feedforward and final heading correction.

Saturation reduces chattering; the coupled wheel-speed safety limit is applied to both controllers. SMC has no independently adjustable speed—both use the Shared reference speed.
