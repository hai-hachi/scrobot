Robot-centered PP carrot, three-position curvature and nominal feedforward

L = shared SMC lookahead radius; h = three-point curvature half-window. Nominal vR is reduced near an open-path endpoint and set to zero for the last 0.025 m of remaining path. The RPP carrot is selected by Nav2's separate RPP algorithm.

Reaching law, saturation boundary and singularity guard

The singular guard δD and all gains are independently tunable in each SMC card. When saturation is disabled, χsat = 0, so the η and ηx contributions vanish.

Physical wheel kinematics (same for RPP, SMC-1s and SMC-2s)

Command limits applied after the full control laws

The drive wheels have radius 0.050 m, 0.420 m wheel-centre spacing and a 95 RPM limit. The rounded 0.50 m/s motor rating is slightly higher than the speed implied by 95 RPM, so 0.49742 m/s is used for each wheel. Individual angular and acceleration limits are tunable, but the coupled wheel RPM limit is enforced after those limits. RPP, SMC-1s and SMC-2s all use the same drivetrain. The ideal SMC reaching identities require a true unicycle reference and no actuator limiting.
