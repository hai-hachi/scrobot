Magnetic field-vector angle is not an absolute heading without axis/declination calibration. The simulation currently does not guarantee realistic sensor noise or long-term gyro bias. RPM-derived wheel heading is useful for comparison even though the EKF intentionally ignores wheel yaw.

CSV logs include raw gyro, accelerometer, magnetic vector, wheel positions/velocities, EKF pose, simulation truth, rates, and relative-motion error report. Gazebo tests cannot establish real-world accuracy without equivalent real-sensor/ground-truth logs.
