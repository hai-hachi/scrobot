Measured MB/s = received uncompressed ROS Image.data bytes / wall time. This excludes DDS overhead and native Gazebo transport. RGB8 uses 3 bytes/pixel; simulated 32-bit floating-point depth uses 4 bytes/pixel (real USB Z16 uses 2).

Four real AprilTag 16h5 textures (IDs 0–3), mounted as two outward-facing plates on each badminton net pole. The scene uses the published court geometry and one lightweight light. AprilTag detections come from the actual apriltag_ros detector, not generated overlay boxes.
