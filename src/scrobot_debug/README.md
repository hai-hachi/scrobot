# scrobot_debug

Debug-only launch composition, monitors, isolated Gazebo fixtures, and RViz
visualization for SC Robot.

Production packages must not depend on this package.

## Main regression launches

```text
description_check.launch.py          URDF / TF / mesh check
camera_check.launch.py               isolated D435i geometry check
control_stack_check.launch.py        command/safety pipeline
manual_control_check.launch.py       production manual control
autonomy_manual_override_check.py    mission pause/resume with MANUAL
localization_check.launch.py         EKF + AprilTag localization
perception_check.launch.py           AprilTag + scan + YOLO perception
yolo_perception_check.launch.py      YOLO/depth 3D validation
yolo_range_gate_check.launch.py      0.50-1.80 m mission gate
yolo_multi_collect_check.launch.py   multi-shuttle selection/reacquisition
smc_shuttle_check.launch.py          local collection controller regression
shuttle_physics_check.launch.py      shuttle physics isolation
collection_check.launch.py           collector geometry
telemetry.launch.py                  consolidated terminal telemetry
rviz.launch.py                       court/robot visualization
```

Synthetic YOLO data are generated by the single canonical launch:

```bash
ros2 launch scrobot_debug yolo_dataset_capture.launch.py
```

## Rule

Debug tools may observe or exercise production interfaces, but must not own
production mission, perception, localization, or control behavior.
